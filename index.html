CSS: a linguagem que dá aparência à web e os frameworks que aceleram o trabalho

Criado nos anos 1990 para separar estrutura e aparência, o CSS ganhou frameworks como Bootstrap e Foundation. Veja como tudo funciona.

O “CSS” (Cascading Style Sheets) é a linguagem que cuida da aparência de uma página web. Enquanto o HTML define a estrutura do conteúdo, como títulos, parágrafos e listas, o CSS define como esse conteúdo é apresentado: cores, fontes, espaçamentos e posição na tela.

A primeira versão oficial foi publicada pelo W3C em 1996, com a proposta de separar estrutura e apresentação. A versão atual, o CSS3, é dividida em módulos e trouxe web fontes, bordas arredondadas, sombras, gradientes e animações.

“O HTML fica com o conteúdo; o CSS cuida do estilo.”

Três frameworks para conhecer

  1. 01
    Bootstrap

    Criado pela equipe do Twitter em 2011, é o mais popular. Mobile-first, usa grid de 12 colunas e 5 breakpoints.

  2. 02
    Foundation

    Também de 2011, usa SASS nativamente e tem o XY grid, com alinhamento vertical e horizontal.

  3. 03
    Semantic UI

    Usa LESS e jQuery, com classes em linguagem natural que deixam o código mais fácil de ler.

Para aplicar CSS, o método mais recomendado é o arquivo externo, ligado ao HTML pela tag link. Ao usar um framework, combine as classes com a marcação da documentação oficial e confira a compatibilidade de versões.
